# Cloud Architecture Roadmap

> Structured enterprise cloud computing curriculum — from systems fundamentals to multi-cloud architecture (AWS, GCP, Azure), IaC, Kubernetes, and Observability.

## Key Capabilities

- **Structured Curriculum Path** — 7 progressive phases covering foundational operating systems through enterprise architecture.
- **Skill Mastery Analytics** — Real-time tracking of completed modules, skill points, and study streaks.
- **Vendor Certification Pathways** — Curated preparation materials for AWS, Azure, GCP, CNCF (CKA), and Linux Foundation exams.
- **Hands-On Lab Integration** — Interactive browser sandboxes for Linux, Docker, Kubernetes, and AWS/GCP/Azure free tiers.
- **Progressive Web App (PWA)** — Offline-first architecture installable on desktop and mobile environments.

## Local Setup & Deployment

1. Clone or download the workspace directory.
2. Serve static files locally (e.g. `npx serve .` or any static HTTP server).
3. To host on GitHub Pages:
   - Push repository contents (`index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`, `icon.svg`).
   - Enable GitHub Pages under **Settings -> Pages** from the `main` branch root directory.

## Core Reference Technologies

- **Linux & Shell**: Bash, Systemd, LVM, SSH security
- **Networking**: TCP/IP, OSI, Subnetting, DNS, HTTP/S
- **Containers & Orchestration**: Docker, Docker Compose, Kubernetes
- **Infrastructure as Code**: Terraform (HCL), Ansible, AWS CloudFormation
- **Security & Observability**: IAM, KMS, Zero Trust, Prometheus, Grafana
