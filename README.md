## 🚀 Deploy on GitHub Pages

1. Create a new GitHub repository (e.g., `cloud-quest`)
2. Upload all files: `index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`
3. Go to **Settings → Pages → Source → main branch → root**
4. Your site will be live at `https://yourusername.github.io/cloud-quest/`

## 📱 Install as App

When visiting in Chrome/Edge on mobile, look for the "Install" banner at the bottom right, or use browser menu → "Add to Home Screen"
